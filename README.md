# 📊 Data Analysis — Power BI Dashboards

A collection of **interactive Power BI dashboards** built to analyze real-world datasets across e-commerce, music streaming, and entertainment platforms. Each dashboard transforms raw data into meaningful visual insights using advanced DAX calculations, custom visuals, and dynamic filtering.

---

## 🚀 Dashboards Overview

### 1. 🛒 Flipkart Sales Dashboard
> **File:** `Flipkartsales.pbix`

- Comprehensive **sales performance analysis** of Flipkart e-commerce data
- Tracks revenue trends, order volumes, and category-wise breakdowns
- Key KPIs: Total Sales, Average Order Value, Top-Selling Categories
- Interactive slicers for filtering by date range, product category, and region

---

### 2. 🎵 Spotify Dashboard
> **File:** `Spotify Dashboard.pbix`

- Deep-dive analytics into **Spotify music streaming data**
- Visualizes track popularity, artist performance, and genre distribution
- Key KPIs: Total Streams, Most Popular Artists, Top Tracks, Genre Split
- Dynamic charts showing streaming trends over time

---

### 3. 🎬 Netflix Dashboard
> **File:** `netflix Dashboard.pbix`

- Detailed **content and viewership analytics** for Netflix
- Analyzes content library by genre, release year, country, and ratings
- Key KPIs: Total Titles, Content Distribution (Movies vs TV Shows), Top Genres
- Geographic visualizations showing content availability across countries

## 📥 How to View the Dashboards

1. Install [**Power BI Desktop**](https://powerbi.microsoft.com/desktop/) (free)
2. Clone this repository or download the `.pbix` files
   ```bash
   git clone https://github.com/sidasyrii/Data-analyst-.git
   ```
3. Open any `.pbix` file in Power BI Desktop
4. Explore the interactive visuals, slicers, and filters!
