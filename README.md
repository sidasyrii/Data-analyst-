# Data Analysis - Power BI Dashboards

A collection of interactive Power BI dashboards for data analysis across different domains.

## Dashboards

| Dashboard | Description |
|-----------|-------------|
| **Flipkart Sales** | Sales analytics dashboard for Flipkart e-commerce data |
| **Spotify Dashboard** | Music streaming analytics and insights from Spotify data |
| **Netflix Dashboard** | Content and viewership analytics for Netflix data |

## Tools Used

- **Power BI Desktop** — for data visualization and dashboard creation

## How to View

1. Download the `.pbix` files from this repository
2. Open them using [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
